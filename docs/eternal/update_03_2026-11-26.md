# Builder Update — Real yield + the first UltraRentz app

**Shipped since the last update**
- **Lending-market yield (Jupiter Lend Earn).** Deposits can now be parked in a Solana lending market while the tenancy runs. At move-out, our keeper withdraws principal + interest and settles everyone in **one transaction**. We call Jupiter by raw CPI, with its account order checked against Jupiter's own SDK IDL (the docs page and the SDK differ, so we went with the SDK). Tested end to end against a Jupiter-compatible test program: 1,200 → 1,236 at 3% → tenant 1,223.40 · landlord 7.20 · UltraRentz 5.40.
- **Security checks.** 5 attack attempts on the yield path are all rejected: a substituted account, an unapproved lending program, a double deposit, early withdrawal to grief the tenant, and settling while funds are still lent out.
- **Tenant web app (React + Tailwind).** Pay a deposit; follow it on a timeline with a live countdown to the automatic refund; see your interest share; respond to a claim (accept, or add evidence — and see plainly that *silence never counts against you*); release your deposit yourself; get a paid-back receipt. Tested in a real browser against the on-chain program, including a full dispute (claim 250 → jurors 50/100/250 → landlord gets the lower median, 100).
- **Code on GitHub:** UltraRentz/ultrarentz-solana.

**Decisions**
- **Jupiter Lend Earn first, Kamino next.** Both pay similar USDC yields (~4.5–5%). Jupiter's Earn integration is the simplest. Because tenants need their deposit back fast, we'll keep part of each deposit un-lent as an instant-refund buffer, since lending markets can hit very high utilisation.

**Challenges**
- Jupiter's SDK only supports mainnet markets, so we built a Jupiter-compatible test program to prove the integration, and will test against real Jupiter on a mainnet fork.
- Newer Solana CLIs default to a new program format, so we pinned the build to the format devnet runs today.

**Next**

- **Deposit Passport:** move your deposit straight to your next tenancy, with the old landlord's claim still protected.
