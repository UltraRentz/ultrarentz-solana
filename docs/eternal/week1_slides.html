Full lifecycle runs on a local Solana validator. Test run: landlord 200 · tenant 1,032.40 · fee 3.60 — every token accounted for.

What we prioritised

Money flow first. Fairness built in.

  • Core flow before frontend: lock → release / dispute → settle
  • Burden of proof on the landlord
  • No quorum = tenant gets everything
  • Absent tenant (e.g. left the country) never defaulted against
  • Protocol fee from yield only — never the deposit
Challenges

What broke — and the fix

  • Settle exceeded Solana's 4 KB stack limit
    → moved large accounts to the heap (Box)
  • New Rust crates broke the default Solana toolchain
    → pinned platform-tools v1.52
